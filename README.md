**BIT240115_FoodManager**

Sinh viên: **Nguyễn Doãn Huy** — MSSV: **BIT240115**.

Ứng dụng được xây dựng bằng **React Native + Expo + TypeScript**, sử dụng **MockAPI qua REST API** để quản lý dữ liệu loại món và món ăn.

**AsyncStorage** lưu dữ liệu và các thay đổi khi offline. Khi có Internet trở lại, ứng dụng **tự động đồng bộ với MockAPI**, không cần bấm nút đồng bộ.
